🆘 TROUBLESHOOTING:

Q: App not loading?
A: Make sure you're opening index.html in a browser, not just file system

Q: Songs not playing?
A: Check if song files are in the "song/" folder with exact names

Q: Images not showing?
A: Check if image files are in "pic/" folder with exact names

Q: GitHub Pages not working?
A: 1. Make sure repo is PUBLIC
   2. Enable Pages in Settings
   3. Wait 5-10 minutes
   4. Clear browser cache (Ctrl+Shift+Delete)

Q: Can't push to GitHub?
A: 1. Install Git: git-scm.com
   2. Set up SSH key or personal access token
   3. Make sure to have created repo on GitHub first

Q: Performance issues?
A: Use Vercel instead of GitHub Pages - it's faster
