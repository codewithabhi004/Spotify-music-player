# Spotify Music Streaming App

A modern, responsive music streaming web application built with HTML, CSS, and JavaScript. Features a mobile-number-based login system, music player, and developer contact information.

## Features

✨ **Modern UI**
- Dark mode Spotify-inspired design
- Fully responsive (mobile, tablet, desktop)
- Smooth animations and transitions
- Beautiful gradient backgrounds

🎵 **Music Player**
- Play/Pause controls
- Next/Previous song navigation
- Audio player with progress bar
- Current song display
- Auto-play next song

🔐 **Authentication**
- Mobile number based login with OTP
- Guest mode access
- Session management

📱 **Responsive Design**
- Mobile-first approach
- Touch-friendly controls
- Works on all screen sizes
- PWA-ready for installable app

👤 **Developer Profile**
- About section with developer details
- Direct contact information
- Social media links
- Share app functionality

## How to Use

### Local Development

1. Clone or download the repository
2. Open `index.html` in your web browser
3. Login with any phone number (10 digits) or use Guest mode
4. Navigate to Music section to play songs
5. Check About section for developer contact

### Features Walkthrough

**Login Page**
- Enter country code (default: +91 for India)
- Enter your 10-digit mobile number
- Or continue as Guest

**Home Page**
- Welcome screen with quick access to music player
- Beautiful hero image with gradient overlay

**Music Player**
- Album art with rotating animation
- Playlist with clickable song cards
- Play/Pause/Next/Previous controls
- Built-in audio player with timeline

**About Section**
- Developer profile information
- Contact details (Phone, GitHub, Instagram, Snapchat)
- App description
- Social sharing buttons (WhatsApp, Facebook, Twitter)
- Copy share link functionality

## Technical Stack

- **Frontend**: HTML5, CSS3, JavaScript (Vanilla)
- **Icons**: FontAwesome 6.4.0
- **Design**: Mobile-first responsive design
- **Audio**: Native HTML5 Audio API

## Installation as PWA (Progressive Web App)

This app can be installed on:
- **Android**: Chrome menu → "Install app"
- **iOS**: Safari menu → "Add to Home Screen"
- **Desktop**: Chrome menu → "Install" or "Create shortcut"
